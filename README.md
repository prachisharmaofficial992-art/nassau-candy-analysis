
# Nassau Candy Analysis Dashboard

## Project Overview
This project analyzes factory-to-customer shipping efficiency for Nassau Candy Distributor using Python and Streamlit.

## Objectives
- Analyze shipping lead time
- Identify efficient and inefficient routes
- Compare ship modes
- Evaluate factory performance
- Geographic shipment analysis

## Tools Used
- Python
- Pandas
- Streamlit
- Plotly
- SQL

## Features
✔ Interactive filters  
✔ Revenue analysis  
✔ Factory efficiency  
✔ Geographic map  
✔ KPI dashboard  
✔ Ship mode comparison  

## Files
- streamlit_dashboard.py
- dataset.csv
- factories.csv

## How to Run
```bash
pip install -r requirements.txt
streamlit run streamlit_dashboard.py
